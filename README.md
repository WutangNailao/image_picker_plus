# Image Picker plugin for Flutter
[![melos](https://img.shields.io/badge/maintained%20with-melos-f700ff.svg?style=flat-square)](https://github.com/invertase/melos)

A Flutter plugin for picking images from the image library, and taking new pictures with the camera.

> Forked from Flutter packages

## Development

This repository uses a Pub workspace. Run dependency resolution once from the
repository root; all packages and the example app will use the local workspace
versions when their version constraints match.

```sh
fvm flutter pub get
fvm dart pub workspace list
```

Run a command across workspace packages with Melos:

```sh
fvm dart run melos run analyze
fvm dart run melos run test
```
